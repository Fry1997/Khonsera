Marker, label & route treatment

The look and the collision rule — so crowded markers survive (the "WEL over ILCE AVENUE" bug).

  • Dot is always drawn; the label can drop. Markers are point-anchored at the centre (not left-anchored), so two close dots never sit on top of each other.
  • Label anchors to the side with room. Each pill renders left or right of its dot by free space; on screen edges it flips inward.
  • Priority collision. When two pills would overlap, the lower-priority one hides (keeping its dot). Priority: origin / destination > changeover. Re-evaluated on every moveend.
  • Pill = ink chip, mono caps. Station code ("WEL") or place name, white on #1a1612, soft contact shadow — reads on any base tone.
  • Route weight is editorial. Thin gold line (2.2) on a soft dark casing (4 @ .46), walk legs a fine 1.6 dotted 1 4. The line should feel drawn, not piped.
  • Out vs back never overlap as one line. Outbound gold, return teal (#1d6f73), drawn with a slight bow so a round-trip reads as two journeys.
  • Flight = great-circle arc in gold, dashed, endpoints only — no road casing.

Why this recreates 1:1

This is a real MapLibre map on a Protomaps vector source, themed by post-processing protomaps-themes-base's light layers — the same path as brandVectorTheme(). To reproduce: take the slot values above into themes/dusk.ts, the geometry into JourneyTheme.geom, and the marker/route paint into journey-map.tsx.
