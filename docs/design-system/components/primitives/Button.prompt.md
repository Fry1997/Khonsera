The one button family — gold (primary), ink (charcoal), ghost (quiet), terra (rare celebratory). Use for any tappable action; only one gold per view.

```jsx
<Button variant="gold" iconLeft={<Icon name="navigation" size={14} />}>Navigate</Button>
<Button variant="ghost" size="sm">Skip</Button>
<Button variant="ink" full>Show boarding pass</Button>
```

Variants: `gold · ink · ghost · terra`. Sizes: `sm · md · lg`. `full` stretches to container width. Spreads native button attributes (onClick, disabled…). Press translates 1px — the stock pushing into the desk.
